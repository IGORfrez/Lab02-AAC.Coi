## Результаты замера Debug vs Release
| Режим | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум |
| ------- | -------: | -------: | -------: | -------: | -------: | ------: |
| Debug   | 1587     | 1641     | 1618     | 1605     | 1553     | 1553 |
| Release | 463      | 484      | 491      | 466      | 474      | 463  |
В моём эксперименте Release оказался быстрее Debug примерно в
3,5 раза.
Что я обнаружил при сравнении IL:
--В Debug присутствуют инструкции nop, которых нет в Release.  
--​В Release уменьшилось количество промежуточных операций с локальными переменными (отсутствуют лишние слоты и команды stloc/ldloc).  
--​Количество IL-инструкций в методе Add() уменьшилось (в Release код метода стал короче и состоит всего из нескольких базовых инструкций).
